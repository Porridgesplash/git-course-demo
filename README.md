# todo-app 待办清单

跟着「Git + GitHub + AI 实战课」一步步做出来的网页版待办清单。

在线使用：https://porridgesplash.github.io/todo-app/

![待办清单截图](images/screenshot.png)

## 功能

- 添加、勾选完成、删除待办
- 刷新页面后数据不丢（保存在浏览器里）
- 按「全部 / 未完成 / 已完成」筛选
- 深色模式，手机上也能正常显示

## 怎么用

- 在线：直接打开上面的网址
- 本地：下载代码后，双击 `index.html` 用浏览器打开

```
git clone https://github.com/Porridgesplash/todo-app.git
```

## 技术

只用了 `index.html`、`style.css`、`script.js` 三个文件，不需要安装任何工具。
